# OctoAcme Project Management Docs

This folder contains guidance for managing OctoAcme's cross-functional projects from initial proposal through delivery and continuous improvement.

## Project management processes

OctoAcme takes a customer-first, iterative approach with clear ownership and measurable outcomes. Projects begin by validating the business need, aligning stakeholders, and agreeing on success criteria. Approved initiatives are planned into prioritized, estimable work with acceptance criteria, milestones, dependencies, and a Definition of Done. Teams execute and track that work on a shared project board, using regular check-ins, reviews, testing, and risk escalation. Releases are prepared with passing checks, release notes, smoke tests, and rollback plans, then verified after deployment. Retrospectives turn lessons into owned improvement actions.
